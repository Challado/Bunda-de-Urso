O que o painel faz

  • Fila de cadastros colaborativos para verificar
  • Editar, verificar, desabilitar e remover (com motivo obrigatório)
  • Marcação falsa e zona sombra (bloqueio geográfico anti-sabotagem)
  • Chaves de acesso (emitir, revogar) e usuários/senhas
  • Histórico e auditoria de cada alteração

A interface completa do painel entra junto com a API de gestão. Enquanto isso, esta página já é o ponto de entrada.
